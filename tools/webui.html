Steel Diver: Sub Wars — Open Sourced

Le lanceur : votre jeu, ses mods, votre sauvegarde. Tout reste sur cet ordinateur.

Le lanceur a été mis à jour : fermez la fenêtre où il tourne et relancez subwars.py.

1. Les fichiers du jeu

Il faut votre copie de Steel Diver: Sub Wars, version européenne (00040000000D7E00), déchiffrée : le .cia de l'eShop, un .cxi ou un .3ds. Le lanceur la cherche dans le dossier cia/ du projet et dans l'émulateur. Rien n'est envoyé nulle part. Sa mise à jour v5200 (0004000E000D7E00, facultative : 16 sous-marins et 3 cartes de plus) se prépare en même temps si son .cia déchiffré est dans cia/.

2. L'émulateur

Azahar refuse le .cia de l'eShop entier (son manuel est resté chiffré) : le lanceur en fait une copie du jeu seul, à installer (Fichier > Installer un CIA), ou un .cxi à ouvrir directement (Fichier > Charger un fichier). Inutile avec un .cxi ou un .3ds. Les mods vont dans chaque émulateur trouvé : Azahar, et ceux de la même famille (Lime3DS, Citra, Borked3DS).

La mise à jour dans l'émulateur

Installée, elle remplace le code du jeu, qu'il soit installé ou ouvert depuis son .cxi : les mods sont alors construits pour elle. Les mods déjà installés pour l'autre version sont retirés (ils empêcheraient le jeu de démarrer) : réinstallez-les ensuite.

3. Les mods

Premium sans l'eShop, triche, caractéristiques des sous-marins, jeu en ligne : onglet Mods. Votre sauvegarde : onglet Sauvegarde.

Mods

Cochez les mods voulus puis « Installer » : ils sont construits à partir de votre jeu et copiés dans l'émulateur (load/mods/00040000000D7E00/, dans chaque émulateur trouvé). Il n'en charge qu'un dossier : tous les mods cochés y vont ensemble. Relancez le jeu ensuite.

Sauvegarde

Fermez le jeu dans l'émulateur avant de modifier la sauvegarde : il garde ses valeurs en mémoire et réécrirait l'ancienne. Une copie de sécurité est faite avant chaque modification.

Caractéristiques des sous-marins

Vos valeurs vont dans votre fichier (), puis le mod Caractéristiques (onglet Mods) les applique au jeu. Les valeurs que le jeu ne supporte pas sont refusées. Prévu pour jouer hors ligne : en ligne, le serveur le traite comme de la triche.

Choisissez un sous-marin dans la liste.

Musique du jeu

Écoutez une musique du jeu, puis remplacez-la par la vôtre : MP3, WAV, OGG, FLAC, M4A… Le lanceur la convertit (canaux et fréquence de l'original, en boucle) et la garde dans votre dossier de réglages. « Appliquer dans l'émulateur » réinstalle vos mods avec le mod Musique ; relancez ensuite le jeu. Rien ne change en ligne : les autres joueurs gardent leur musique.

Rien en écouteChoisissez « Écouter » sur une musique.

Serveur en ligne

Pour jouer en ligne entre amis, un joueur lance le serveur sur son ordinateur et chacun installe le mod Jeu en ligne avec son adresse. Le serveur demande à la box d'ouvrir ses ports (UPnP) : les amis peuvent jouer depuis chez eux, par Internet.

Configuration du serveur

Les options de serveur.toml. « Enregistrer » les écrit dans le fichier (ses commentaires restent) ; un serveur qui tourne les prend en compte quand on le relance.

Chargement…

Rejoindre le serveur d'un ami

Entrez l'adresse qu'il vous donne (IP ou nom, avec :port s'il n'utilise pas 61000). « Tester » vérifie depuis cet ordinateur que son serveur répond ; puis installez le mod Jeu en ligne avec cette adresse.

Journal

En bref

  1. Jeu : le lanceur trouve votre copie du jeu et en extrait les fichiers dont les mods ont besoin.
  2. L'émulateur (Azahar, ou Lime3DS, Citra, Borked3DS) : installez le .cia préparé, ou ouvrez le .cxi.
  3. Mods : cochez Premium (version complète et les 23 sous-marins), et si vous voulez la Triche, vos Caractéristiques, le Jeu en ligne. Installez, relancez le jeu.
  4. Sauvegarde : tout débloquer, des médailles d'or, retirer le drapeau premium d'une ancienne sauvegarde.
  5. Musique : écoutez les musiques du jeu et remplacez celles que vous voulez par les vôtres (MP3, WAV…) ; un bouton remet celles d'origine.

Questions

Le premium sans l'eShop ? Tout le contenu premium est déjà dans le jeu gratuit ; l'achat n'ajoutait qu'un droit. Le mod le donne, et donne aux cinq sous-marins historiques leur coque à la place de leur proue, qui était dans le contenu payant.

La mise à jour v5200 ? La dernière mise à jour du jeu (16 sous-marins, 3 cartes, des règles revues). Avec son .cia déchiffré dans cia/, le lanceur la prépare et l'installe dans l'émulateur (onglet Jeu). Les mods sont construits pour la version que l'émulateur fait tourner ; chaque mod indique les versions avec lesquelles il marche (onglet Mods).

Retirer les mods ? Onglet Mods, « Retirer les mods de l'émulateur ». Les déblocages restent dans la sauvegarde.

Le jeu affiche l'erreur 098-0101 au démarrage ? La sauvegarde a été marquée « premium » : onglet Sauvegarde, « Retirer le drapeau premium », ou installez le mod Premium.

En ligne, la triche ? Le serveur sait quels mods vous avez : selon sa configuration, les tricheurs (Triche, Caractéristiques) ne jouent qu'entre eux, avec tout le monde, ou pas du tout. Premium n'est pas de la triche.
