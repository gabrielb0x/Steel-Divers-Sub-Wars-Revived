Set up the game

Bring your own copy of Steel Diver: Sub Wars (Europe) and, if you have it, its last update v5200 (16 more submarines, 3 more maps): a .cia, encrypted or not, or a decrypted .3ds or .cxi. The launcher finds them (the project's cia/ folder, your Downloads, Desktop and Documents, the emulator), decrypts them if needed, and installs everything into the emulator. Nothing is sent anywhere.

    Drop your game or update file here or click to choose it: .cia, .3ds or .cxi

    Then

    Premium without the eShop, cheats, submarine characteristics, online play, your music: Mods tab. Your save: Save tab.

    Details and manual steps

    The game's files

    Extracts the files the mods need from a copy you choose on this computer (the setup does it from the best copy found).

    A copy for the emulator

    The eShop .cia holds the manual still encrypted, which Azahar refuses: the launcher makes a copy of the game alone (File > Install CIA) and a .cxi (File > Load File), in build/azahar/. The setup installs the game without them.

    The update in the emulator

    Once installed, it replaces the game's code, whether the game is installed or opened from its .cxi: the mods are then built for it. The mods installed for the other version are removed (they would keep the game from starting): install them again afterwards.

    Mods

    Tick the mods you want, then "Install": they are built from your game and copied into the emulator (load/mods/00040000000D7E00/, in every emulator found). It only loads one folder: all the mods ticked go into it together. Restart the game afterwards.

    Save

    Close the game in the emulator before changing the save: it keeps its values in memory and would write the old ones back. A backup is made before every change.

    Submarine characteristics

    Your values go into your file (), then the Characteristics mod (Mods tab) applies them to the game. Values the game does not support are refused. Meant for offline play: online, the server treats it as cheating.

    Choose a submarine in the list.

    The game's music

    Listen to a music of the game, then replace it with yours: MP3, WAV, OGG, FLAC, M4A… The launcher converts it (the original's channels and rate, looping) and keeps it in your settings folder. "Apply in the emulator" installs your mods again with the Music mod; then restart the game. Nothing changes online: the other players keep their music.

    Nothing playingChoose "Game" or "Yours" on a music.

    Online server

    To play online with friends, one player runs the server on their computer and everyone installs the Online play mod with its address. The server asks the router to open its ports (UPnP): friends can play from home, over the Internet.

    Server configuration

    The options of server.toml. "Save" writes them to the file (its comments stay); a running server takes them into account when it is restarted.

    Join a friend's server

    Enter the address they give you (IP or name, with :port if it does not use 61000). "Test" checks from this computer that their server answers; then install the Online play mod with this address.

    Log

    In short

    1. Game: "Set everything up" finds your copy of the game and its update (or drop them there), decrypts them if needed, extracts the files the mods need and installs both into the emulator (Azahar, or Lime3DS, Citra, Borked3DS).
    2. Mods: tick Premium (the full version and every submarine), and if you like Cheats, your Characteristics, Online play, Music. Install, restart the game.
    3. Save: unlock everything, gold medals, clear the premium flag of an old save.
    4. Music: listen to the game's music and replace the ones you want with yours (MP3, WAV…), at the same loudness; a button brings the originals back.

    Questions

    Premium without the eShop? All the premium content is already in the free game; the purchase only added a right. The mod gives it, and gives the five historical submarines a prow of the game in place of theirs, which was in the paid content.

    The update v5200? The game's last update (16 submarines, 3 maps, revised rules). Drop its .cia on the Game tab, even encrypted: the launcher decrypts it, prepares it and installs it into the emulator. The mods are built for the version the emulator runs; each mod says which versions it works with (Mods tab).

    An encrypted file? Azahar needs the game and its update decrypted. The launcher decrypts them on your computer with the decryptor of Batch CIA 3DS Decryptor Redux (downloaded from GitHub, checked by its SHA-256), run directly on Windows and with Wine on Linux and macOS: yours, or a portable one downloaded for it and removed afterwards. Only Steel Diver: Sub Wars and its update are decrypted.

    Remove the mods? Mods tab, "Remove the mods from the emulator". The unlocks stay in the save.

    The game shows error 098-0101 at start-up? The save was flagged "premium": Save tab, "Clear the premium flag", or install the Premium mod.

    Cheating online? The server knows which mods you have: depending on its configuration, cheaters (Cheats, Characteristics, Submarine speed) only play together, with everybody, or not at all. Premium and Music are not cheating.
