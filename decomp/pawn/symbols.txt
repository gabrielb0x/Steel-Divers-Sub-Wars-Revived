# Names for the Pawn scripts, applied by tools/amxdec.py (see tools/amxsym.py).
#
#   <script>:<address> <name>(<parameters>)  [<file.inc>]   function
#   <script>:g_<address> <name>                              global variable
#
# A function name applies to every copy of the function in the other scripts (same normalised
# code); a global name to every script whose matching functions use that global. Parameters are
# in Pawn syntax: const name[] (string), name[] (array), Float:name, &name (by reference), tags
# of decomp/pawn/natives.inc (BUTTON:name), "..." (variadic).
# The game's own names (from its log strings) need no entry; give parameter names by repeating it.
# Names written here are ours: keep them descriptive, and only for code that has been read.
